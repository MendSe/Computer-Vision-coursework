## Technologies Used

## Assignments

### HW1: Image Processing & Filters
* **Topics Covered:** Linear filtering, edge detection, image convolutions, and morphological operations. 
* **Highlights:** Implemented custom convolution functions from scratch to understand the mathematics behind image transformations.

### HW2: Feature Detection & Image Stitching
* **Topics Covered:** Harris Corner Detection, SIFT feature extraction, feature matching, and homography computation. 
* **Highlights:** Created a panorama image stitcher by computing homographies and applying RANSAC for robust outlier rejection.

### HW3: Deep Learning & Neural Networks
* **Topics Covered:** Convolutional Neural Networks (CNNs), image classification, and fine-tuning pre-trained models. 
* **Highlights:** Built and trained a CNN to classify images, exploring techniques like data augmentation and dropout to prevent overfitting.
